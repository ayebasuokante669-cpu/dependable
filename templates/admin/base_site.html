{% extends "admin/base_site.html" %} {% comment %} A light SCHOOLCORD skin over Django's admin. Deliberately not a rebuild: the admin is an internal tool for support work, and every hour spent restyling it is an hour not spent on the screens a school actually uses. This stops it looking like a stock Django install -- brand blue in the header and breadcrumbs, and the same 8px corner the design system uses everywhere else. Nothing structural, and no override of the branding block: `admin.site.site_header` in config/urls.py already reads SCHOOLCORD from apps/core/branding.py, so the name arrives on its own. Extending a template of the same name is the documented way to override an admin template -- Django's loader continues past this file when resolving the parent, so this is not recursion. The hex values are literal rather than the Tailwind custom properties because the admin does not load app.css, and pulling the whole stylesheet in to colour one bar would be the rebuild this is avoiding. They match --color-brand-* in assets/app.css; if those move, move these. {% endcomment %} {% block extrastyle %} {{ block.super }} {% endblock %}
