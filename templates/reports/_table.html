{% comment %} One of a report's breakdowns. Takes `table` -- an apps.reports.structure.Table. Every cell arrives already formatted, so this template only decides where things sit: it adds up nothing, formats nothing, and reverses no URLs. That is what keeps this grid and the same grid in the PDF honest about each other. Rows are walked as `table.filled_rows`, which pairs each cell with its column -- see structure.Filled for why the pairing is not done here. Three things are worth knowing: * a column marked `bar` is the figure in the column beside it, drawn. It is decoration for an eye scanning down the page, so it is hidden from screen readers, which already have the number, and hidden below `sm`, where there is no room for a picture of a number; * the total row is the view's, not the template's -- a template that summed a column would be a second source of truth for it; * the footnote is not decoration. Every one of these grids leaves something out, and the note says what. {% endcomment %}
