{% comment %} The school logo control: the one place a school actually changes its mark. Takes `school` (for the current logo), `field` (the form's logo file field) and `remove_field` (its "remove the current logo" checkbox). Both fields are absent for an account that may not change the logo, and this partial then renders the read-only half. The problem this replaces: `{{ form.logo }}` rendered Django's stock ClearableFileInput -- a bare "Choose file" next to the words "Currently: logos/…/file.png" -- which people did not read as *the* place to add a logo, and which showed a file path rather than the image. So the control now shows the thing itself: the logo as it stands, at the size it is used, with a labelled button beside it. The
