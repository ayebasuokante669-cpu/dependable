{% comment %} Light/dark switch. A two-position control rather than one icon that flips: with a single button the icon has to stand for either the current theme or the one you would get by pressing it, and users reliably read it as the wrong one. Two pressed-states say which theme is on with no convention to learn. State lives in localStorage under `schoolcord-theme`, read before first paint by the inline script in base.html. Untouched, it follows the operating system -- so this renders with neither option pressed until a choice is made, which is accurate: neither has been chosen. Ships `hidden` and is revealed by js/ui.js: switching themes is entirely a client-side affair, so without the script this would be a control that visibly does nothing. The theme itself still applies -- the inline bootstrap in base.html reads the stored value with or without ui.js. Pass `on_panel=True` when it sits on the navy sidebar rather than on a card. {% endcomment %}
